# 人物替换：场景适配与多图小差分

用于人物替换的角色适配重演，以及 A／B／C 模式中的批量变体或组图。这里只扩展已授权的设计范围，不改写用户明确指定的背景、服装、文字、构图、姿势和交付数量。

## 先确定保留到什么程度

- **忠实还原**：用户明确要求一比一、仅换人物、背景不变或动作完全一致时，锁定对应项目；没有允许变化的动作不加入小差分。若同时要求“动作完全一致”和“小差分”，可先将差分安排到未锁定的视线、表情或取景，不擅自解锁动作。
- **角色适配重演**：通常的人物替换保留原图情绪、互动意图、核心接触与画法，允许重设计环境、取景及细微动作，使其适合新角色。保留姿势意图不等于逐像素复刻轮廓。
- **自由创作**：用户明确要求新场景、新活动或大幅变化时，按 C 模式设计；不因多图就自行改变任务核心。

固定项由用户要求和角色辨识决定；可变项应写清范围。不可把“所有细节完全不变”和“背景动作自由改编”同时写进提示词。

## 场景适配角色

有目标角色参考或设定时，依据已确认的服装、身份与世界观选一个具体地点，确定主要陈设、活动空间和光源；缺少职业、阵营或故事信息时，不从衣服擅自认定。无明确世界观时，可采用与服装视觉协调的中性空间。

背景适配需要落实空间布局、建筑或家具形态、道具用途和光源，不能只把原背景换色或随意撒角色标志。确保动作在该环境中有合理的支撑、距离和接触对象。角色穿着不因换场景自行更改；指定保留原衣服仍按原图服装执行。

保留原画法及色彩组织规律，新光照依据新场景重新落地，人物与背景共用受光、接触阴影、材质和景深。原图的固定窗光、反射及环境染色不原封不动贴到新的地点。

画风与场景内容分别迁移。用户要求换背景或清理原图元素时，保留已确认的明暗概括、边缘和细节密度，同时替换原场景物体、符号、光效图形、支撑面及其投影／反射，不把改色或增加新背景当作已清理旧元素。仅在角色或新场景确有依据时保留相应装饰；没有换背景要求的忠实还原不据此擅自删除内容。不要把某次成功案例的列车、雨窗、配色或柔灰画法固化为默认场景。

只有 A 模式原图、没有新角色时，提供【新角色参考／设定】与明确的场景适配指令即可，不编造具体角色事实、不要求补图。生成时应先确定一套适配场景再执行各张，不能把多个互斥地点同时塞进单张提示词。

## 多图先区分关系，再分配差分

1. **同一分镜的变体**：保留核心动作和接触关系，默认每张选两三个细节变化，如视线落点、头部微倾、眉眼张力、嘴部开合、肩部高低、手腕角度或镜头轻微偏移。幅度是同一动作相邻瞬间，不变成新活动。
2. **连续分镜**：先保留各张的叙事任务及前后反应，再给每张分配具体表情和动作；同一地点的布局、光向、陈设、衣服和道具状态前后连贯。需要换地点或时间时，以用户要求或明确的叙事转场为依据。
3. **独立作品**：身份及指定画法保持一致，背景可以分别设计；不要把多张不同参考强制塞进同一连续场景。

为实际请求的每张写出“固定项＋本张差分”，而不是每段复制同一长提示词后追加“略有不同”。独立调用时每张提示词应自包含，或明确“公共段＋编号分镜段”的组合方式，不能依赖模型记得上一张。

例如同一询问动作的三个变体：第一张 A 看向 B、嘴唇轻启；第二张 A 目光移向两人的手、下巴略低；第三张 A 回望 B、眉头稍紧。B 与 A 的既定握腕关系保持；手腕朝向微调须仍满足手指接触与关节范围。不要靠新增道具、改变人数或更换服装制造小差分。

多张数量按用户要求，不因本示例固定为三张。组图默认小差分只在用户请求多图时生效，不自动扩展单张任务或触发图像生成。用户要求分别给图时不拼成一张。

## 交付前核对

- 场景是否有具体适配设计；未提供新角色时是否仅保留合法插槽而无虚构身份？
- 用户的明确锁定项是否被保留；角色适配是否仍保留核心互动和情绪？
- 每张差分是否具体可执行且互相有区别；是否在无授权情况下把小差分改成换动作、换服装或新亲密接触？
- 连续分镜是否保留各自情节、环境空间和光照连续性；独立作品是否被错误锁成同一背景？
- 新姿势是否仍满足主技能的人体、手部与足部约束；仅交付提示词时不声称已验证实际成图差异？
