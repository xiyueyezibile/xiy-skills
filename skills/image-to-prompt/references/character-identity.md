# 人物替换：辨识特征提取与覆盖核对

B 身份提取与 C 场景创作模式读取，解决给了人物图却只写“遵循参考”而遗漏特征的问题。也可依据明示文字整理特征，注明来源。A 通用替换模板无需目标图或本清单。下文底图职责只适用于 B；C 无需底图，场景、姿态和神态按用户描述及新设计决定，画法按用户指定、风格参考、人物图画法的优先级选择。

## 1. 分清素材职责

先确定可用素材的职责。沿用用户已有指定；多图用途确实不明时只询问关键对应关系，不自行交换。只有人物图且要求提取元素时走 B，只输出身份段，不索要底图或编造场景；要求按描述创作新画面时走 C，身份段与新设计整合。B 已有底图与目标素材时再整合替换提示词。

| 内容 | 默认来源 | 用户指定时的覆盖方式 |
| --- | --- | --- |
| 镜头、姿势、神态、遮挡、裁切 | 底图提供核心关系；C 由本次设计提供 | 明确锁定项保持；角色适配与小差分按主技能授权范围调整，不从身份图继承其原视角或表情 |
| 成图媒介与画法 | 用户明确指定 > 专用风格参考 > A／B 底图表现；C 无风格要求时沿用人物图 | 显式3D／真人化按已选分支重新表现，不同时混入冲突的立绘描边、固定阴影与摄影质感 |
| 场景及光照 | 保留场景时依据底图；角色适配时依据已选新场景；C 由本次设计决定 | 用户明确保留的背景、光向等优先，选能支持锁定条件的场景；新角色的接触阴影与反射随其形体重建 |
| 脸型、发型、发色、眼部特征、身份性配饰、体型 | 新角色参考 | 可单独指定保留原体型或某件原配饰 |
| 服装及其附属装饰 | 新角色参考 | “保留原图衣服”时沿用底图服装及衣物附属装饰 |

本表按主技能的“忠实还原／角色适配重演／场景创作”和逐项覆盖执行，不另设“场景镜头一律不可改”的隐含规则。变化范围有冲突时先沿用最新明确要求；身份、动作、媒介和光照分别确定职责，不能互相覆盖。

眼镜、独立发夹、角色本身的耳朵等通常属于身份特征；衣领蝴蝶结、裙边花纹、服装扣件通常随服装。跨类别或用途不明的部件按用户要求与图像证据处理，不把“保留原衣服”扩大为保留底图人物的全部配饰。

旧任务对体型、战损、服装或配饰的修改不自动传给新任务。目标角色没有底图的角、兽耳、尾巴或光环时，不因其显眼而默认保留；若用户明确指定保留，再把它列为覆盖项。钢琴、花瓶等场景道具与角色身份分开处理。

更换身份后同时检查旧角色轮廓残留：发束长度、发型轮廓和根部连接，袖型、领口、裙摆与飘带等均按本次服装／身份来源重绘，不能只换色或面部而沿用旧角色的长发、衣装碎片。目标角色本来具有的部件与用户明确保留的原衣服照常保留，不将同类部件一概删除。A 无目标图时写明这一迁移规则，不编造目标的具体排除清单。

## 2. 逐区观察，建立辨识清单

检查头部、脸部、躯干和画内四肢，选择能区分该角色的实际特征，不机械要求所有类别都有内容。小配饰难以辨认且影响身份时，可查看原分辨率或局部放大；放大仍不清楚就标为无法确认。

| 观察区 | 优先抓取的信息 | 描述要点 |
| --- | --- | --- |
| 头发 | 长短、整体轮廓、刘海分区、分缝、辫子或马尾、卷曲、呆毛 | 分清固有发型与风或姿势造成的摆动 |
| 发色 | 基础色、挑染、发尾渐变、异色内层 | 写清分布位置；不要把亮部当成另一种发色 |
| 面部可见结构 | 脸部宽长关系、眼形与眼距、眉眼关系、鼻部轮廓、口唇比例、颧颊和下颌形态 | 仅记录可观察且能区分身份的关系；区分固有形态与表情、透视、光影造成的变化，不虚构数值或被遮挡结构 |
| 眼睛与局部标记 | 瞳色、异色瞳、瞳孔形状、固定眼部图案、痣或疤痕 | 区分固有图案与普通高光；神态及视线来自本次动作方案 |
| 身份配饰与结构 | 眼镜、发夹、耳饰、头饰、角、耳朵、尾巴、光环等 | 用形状、颜色、数量、位置与连接关系区分，而非只写“有配饰” |
| 服装 | 领口、袖型、层次、剪裁、扣件、主要纹样、鞋袜 | 仅在本次服装来源为目标图时迁移；避免遗漏小件而只写衣物大类 |
| 体型与肢体标记 | 头身比、身体轮廓、画内纹样、饰物 | 来源按职责表确定，不把底图比例或目标立绘动作混入 |

每条记录包含：**具体特征、来源依据、本次保留状态、目标构图中的可见性**。面向用户可合并同类特征，只展示有用信息；无需交付完整分析表。

- **必须保留**：可确认、允许迁移的辨识特征。优先级高的身份特征先写，但不能以“只选三项”为由漏掉其余可见必要特征。
- **按本次要求替换或排除**：例如保留底图晚礼服时，目标角色的衬衫、领带与裙装不迁移；底图独有发饰默认被替换。
- **无法确认**：模糊图案、看不到的背面或互相矛盾的版本。保留不确定性；只有会影响替换决定时才询问，不编造细节。

位置优先用“画面左侧”等图像坐标；只能确定角色自身左右时才用该表述。改变头部朝向后，配饰随所属发束或身体转动，不机械锁在原参考图的屏幕坐标。多张目标图中的不同服装版本、配饰组合不拼接；用户指定的版本优先，未指定且差异影响身份时确认版本。

### 面部身份与转视角

2.5D、3D及真人任务中，从上表选出实际可辨的面部关系写入身份段，并按成图媒介表达，不只列发色、瞳色与配饰。身份描述与动作描述分开：眼形和下颌属于身份，眼睑开合、嘴部表情和转头属于本次动作；阴影不当作固有鼻形或脸部轮廓。

- 真人换真人：保留目标人物可观察的脸部宽长、五官相对关系与轮廓特征，目标脸在底图角度下重新表现。不能沿用底图人物的颧颊、鼻部和下颌后仅替换发色、肤色，也不无依据统一成大眼、小鼻或尖下巴。
- 2D到绘画式2.5D／3D：保留角色的眼型特征、脸部轮廓意图与五官布局，在指定的造型夸张程度下建立体积和转面。卡通眼睛可维持有意夸张，不能直接贴二维眼睛或仅靠皮肤高光制造立体感。
- 明确要求动漫真人化：将可见设计特征转译为合理的真人面部比例与实物服饰，不把动漫夸张比例全部当作真人测量。单张动漫图不能确定唯一真人长相；允许合理设计补全，但不将补全说成已提取的事实。

转头、俯仰或表情变化后，近远眼的大小、鼻部遮挡、口部透视、颊部与下颌轮廓须彼此对应，不能仍复制正面立绘的对称像素位置。不为显示特征强行转正脸；单张参考看不见的侧面、隐侧眼睛或背面不声称已准确提取。已有多角度参考时保持同一人的关系，不混合不同人的五官。

## 3. 将特征落实到可复制提示词

开头写清素材职责及覆盖项，单独加入“新角色特征约束”。B 区分底图与目标角色；C 区分人物图身份、文字要求及创作补全，不能把新设计说成图中事实。使用具体特征，不只留“完全忠于角色设定”或“保留全部配饰”。C 不套用下文底图姿态、遮挡或光照，按新方案核对身份可见性。

特征段应能独立理解：颜色与位置明确，相关部件的关系连贯。服装结构、手部比例或其他局部细节可写在对应段，但最终代码块必须包含全部必要描述，不能只存在于块外清单。

保留目标角色的基础颜色、标志性形状和本次可见的面部结构，再用已选成图媒介、场景光照与阴影表达；原图的强调色不能无依据改掉目标发色、瞳色或异色分区，环境照明导致的合理色偏仍保留。眼镜随脸部透视变形，发饰随发束，尾巴从合理位置连接，避免漂浮或与身体穿插。

辨识优先级不等于必须全部露出。背面图案、画外鞋袜、被刘海遮住的眼睛等按本次已确认的构图与遮挡处理，不为展示身份特征擅自增加全身视角、额外眼睛或展示动作；已授权的取景适配不被原底图重新锁死。无文字要求与服装文字图案冲突时，按用户要求保留配色和非文字形状，移除文字，并说明该覆盖项。

### 示例：保留原衣服，目标角色戴眼镜

假设目标图可确认粉红长卷发、黑框圆眼镜、黑色猫耳和交叉发夹；用户要求沿用底图黑色晚礼服及坐姿。提示词应具体迁移这些身份特征，服装段描述原礼服，不迁移目标图的衬衫、领带和短裙。不能把眼镜归入衣服后一起丢弃，也不能保留底图独有的发饰来凑完整。

### 示例：异色特征被遮挡

目标参考显示左右瞳色不同，底图头部转向使一只眼被遮挡。保留可见眼睛对应的颜色，隐侧维持遮挡；不为显示异色瞳改变回头角度。若无法判断目标图是否镜像，不猜测左右归属。

## 4. 交付前核对，收到生成图后再验收

逐项将辨识清单与最终提示词对照：每个必须保留项应有具体描述，或有用户覆盖、合理遮挡、裁切的原因。除头发分区、挑染、眼睛、配饰及非人类结构外，2.5D／3D／真人还核对面部关系与转视角处理，避免“配色配饰都对却仍是底图的脸”。同时排除底图角色独有特征和相互冲突的服装版本。

A 模式直接交付带身份插槽的通用模板，不附“缺少新角色图”的提示或未完成清单。用户之后补图并要求提取特征时，转入 B 模式重新观察并补全特征段，不原样重复模板。B 模式只有文字设定时使用明示事实，不假装已检查角色图。

用户提供生成结果后，逐项区分“已保留、遗漏、变形、被合理遮挡”。只针对实际问题提出局部编辑，例如恢复眼镜轮廓或正确的发夹组合，同时固定已正确的姿势、服装与画风；不能因补一件配饰而重做整幅图。提示词检查只能确认描述覆盖，不能保证模型必然正确生成每个细节。

面部身份偏离时，先指出哪组可见关系偏离，再限制在脸部及必要的发际线／下颌过渡修正，保留正确的头部朝向、表情、衣服和环境；照明问题修对应受光，不以磨皮、锐化或重换整张脸掩盖原因。只调整提示词时不声称已完成真人身份或三维结构验收。
