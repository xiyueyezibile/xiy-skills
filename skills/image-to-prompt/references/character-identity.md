# 人物替换：辨识特征提取与覆盖核对

仅“B：新角色辨识特征提取”模式读取。解决“给了新角色图，但提示词只写遵循参考，生成时遗漏特征”的问题；也可依据用户明示的文字设定整理特征，注明依据来自文字而非图像。只给原图、要通用替换模板属于 A 模式，不需要目标图或本清单，也不视为素材不足。

## 1. 分清素材职责

先确定可用素材的职责。沿用用户已有指定；多图用途确实不明时只询问关键对应关系，不自行交换。只有新角色图且用户要求反推角色元素时，输出身份特征段即可，不索要底图或编造场景；已有底图与目标素材时再整合完整替换提示词。

| 内容 | 默认来源 | 用户指定时的覆盖方式 |
| --- | --- | --- |
| 镜头、姿势、神态、遮挡、裁切、画风、光照、场景 | 底图 | 仅改用户明确要求变化的部分 |
| 脸型、发型、发色、眼部特征、身份性配饰、体型 | 新角色参考 | 可单独指定保留原体型或某件原配饰 |
| 服装及其附属装饰 | 新角色参考 | “保留原图衣服”时沿用底图服装及衣物附属装饰 |

眼镜、独立发夹、角色本身的耳朵等通常属于身份特征；衣领蝴蝶结、裙边花纹、服装扣件通常随服装。跨类别或用途不明的部件按用户要求与图像证据处理，不把“保留原衣服”扩大为保留底图人物的全部配饰。

旧任务对体型、战损、服装或配饰的修改不自动传给新任务。目标角色没有底图的角、兽耳、尾巴或光环时，不因其显眼而默认保留；若用户明确指定保留，再把它列为覆盖项。钢琴、花瓶等场景道具与角色身份分开处理。

## 2. 逐区观察，建立辨识清单

检查头部、脸部、躯干和画内四肢，选择能区分该角色的实际特征，不机械要求所有类别都有内容。小配饰难以辨认且影响身份时，可查看原分辨率或局部放大；放大仍不清楚就标为无法确认。

| 观察区 | 优先抓取的信息 | 描述要点 |
| --- | --- | --- |
| 头发 | 长短、整体轮廓、刘海分区、分缝、辫子或马尾、卷曲、呆毛 | 分清固有发型与风或姿势造成的摆动 |
| 发色 | 基础色、挑染、发尾渐变、异色内层 | 写清分布位置；不要把亮部当成另一种发色 |
| 脸与眼睛 | 脸型、瞳色、异色瞳、瞳孔形状、固定眼部图案、痣或疤痕 | 区分固有图案与普通高光，表情仍由底图决定 |
| 身份配饰与结构 | 眼镜、发夹、耳饰、头饰、角、耳朵、尾巴、光环等 | 用形状、颜色、数量、位置与连接关系区分，而非只写“有配饰” |
| 服装 | 领口、袖型、层次、剪裁、扣件、主要纹样、鞋袜 | 仅在本次服装来源为目标图时迁移；避免遗漏小件而只写衣物大类 |
| 体型与肢体标记 | 头身比、身体轮廓、画内纹样、饰物 | 来源按职责表确定，不把底图比例或目标立绘动作混入 |

每条记录包含：**具体特征、来源依据、本次保留状态、目标构图中的可见性**。面向用户可合并同类特征，只展示有用信息；无需交付完整分析表。

- **必须保留**：可确认、允许迁移的辨识特征。优先级高的身份特征先写，但不能以“只选三项”为由漏掉其余可见必要特征。
- **按本次要求替换或排除**：例如保留底图晚礼服时，目标角色的衬衫、领带与裙装不迁移；底图独有发饰默认被替换。
- **无法确认**：模糊图案、看不到的背面或互相矛盾的版本。保留不确定性；只有会影响替换决定时才询问，不编造细节。

位置优先用“画面左侧”等图像坐标；只能确定角色自身左右时才用该表述。改变头部朝向后，配饰随所属发束或身体转动，不机械锁在原参考图的屏幕坐标。多张目标图中的不同服装版本、配饰组合不拼接；用户指定的版本优先，未指定且差异影响身份时确认版本。

## 3. 将特征落实到可复制提示词

开头先写清两类参考职责和本次覆盖项，随后单独加入“新角色特征约束”。使用观察到的具体特征，不能只留“完全忠于角色设定”或“保留全部配饰”等笼统句。

特征段应能独立理解：颜色与位置明确，相关部件的关系连贯。服装结构、手部比例或其他局部细节可写在对应段，但最终代码块必须包含全部必要描述，不能只存在于块外清单。

保留目标角色的基础颜色和标志性形状，再用底图画法、环境光与阴影表达；原图的强调色不能把目标发色、瞳色或异色分区改掉。眼镜随脸部透视变形，发饰随发束，尾巴从合理位置连接，避免漂浮或与身体穿插。

辨识优先级不等于必须全部露出。背面图案、画外鞋袜、被刘海遮住的眼睛等维持底图裁切与遮挡，不增加全身视角、额外眼睛或展示动作。无文字要求与服装文字图案冲突时，按用户要求保留配色和非文字形状，移除文字，并说明该覆盖项。

### 示例：保留原衣服，目标角色戴眼镜

假设目标图可确认粉红长卷发、黑框圆眼镜、黑色猫耳和交叉发夹；用户要求沿用底图黑色晚礼服及坐姿。提示词应具体迁移这些身份特征，服装段描述原礼服，不迁移目标图的衬衫、领带和短裙。不能把眼镜归入衣服后一起丢弃，也不能保留底图独有的发饰来凑完整。

### 示例：异色特征被遮挡

目标参考显示左右瞳色不同，底图头部转向使一只眼被遮挡。保留可见眼睛对应的颜色，隐侧维持遮挡；不为显示异色瞳改变回头角度。若无法判断目标图是否镜像，不猜测左右归属。

## 4. 交付前核对，收到生成图后再验收

逐项将辨识清单与最终提示词对照：每个必须保留项应有具体描述，或有用户覆盖、合理遮挡、裁切的原因。重点查头发分区、挑染、瞳孔图案、眼镜、成组小饰物及非人类结构；同时排除底图角色独有特征和相互冲突的服装版本。

A 模式直接交付带身份插槽的通用模板，不附“缺少新角色图”的提示或未完成清单。用户之后补图并要求提取特征时，转入 B 模式重新观察并补全特征段，不原样重复模板。B 模式只有文字设定时使用明示事实，不假装已检查角色图。

用户提供生成结果后，逐项区分“已保留、遗漏、变形、被合理遮挡”。只针对实际问题提出局部编辑，例如恢复眼镜轮廓或正确的发夹组合，同时固定已正确的姿势、服装与画风；不能因补一件配饰而重做整幅图。提示词检查只能确认描述覆盖，不能保证模型必然正确生成每个细节。
