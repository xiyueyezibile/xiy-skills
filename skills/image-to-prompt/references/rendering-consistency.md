# 人物替换：成图媒介、立体身份与渲染统一

适用于跨媒介替换、2.5D／3D／真人摄影，以及贴片感、脸不像或材质不协调的修正。**成图媒介**指最终图片要呈现的表现方式，区别于目标角色参考图自身的媒介。本页描述视觉证据与执行步骤，不凭观感推断引擎、模型或制作流程。

## 1. 先确定成图媒介和参考职责

选择优先级：用户明确指定 > 专用风格参考 > A／B 底图的可见表现；C 未指定且无风格参考时沿用人物图表现。用户只说“更高清”不构成换媒介授权。先选定一个主分支，再写提示词，不把互斥方案交给生成模型自行选择。有意混合媒介时逐层指定表现，不强制统一掉设计。

- **身份来源**：目标角色提供本次允许迁移的面部关系、发型、固有颜色、体型、服饰及标志结构；具体提取见 [character-identity.md](character-identity.md)。身份不等于发色和配饰的集合，也不等于目标立绘的固定阴影。
- **姿势与镜头来源**：按主文件确定的参考职责和用户锁定项执行。动作、眼神方向、表情造成的面部形变不能误记成身份结构；换角度时需要重新投影同一张脸。
- **场景来源**：按 [adaptation-and-variants.md](adaptation-and-variants.md) 区分角色适配重演和明确保留项。保留地点与光照不等于保留底图人物的骨相、皮肤或固定高光；改场景也不自动授权更换画法。

A 模式没有目标角色图时，使用【新角色参考／设定】及可执行的身份迁移规则，不分析不存在的脸或索要非必需素材。B 只有身份图时只提取身份，可注明成图媒介待后续任务确定，不编造底图、光源或背景。C 按本次设计选媒介、场景和光照，不假设有底图。**只提取风格**时仅输出可迁移的表现规律与主体插槽，不要求身份段、姿态或具体人物特征。

## 2. 五种表现方式分别处理

这些是视觉分支，不是制作来源鉴定。边界模糊时直接描述造型、边缘、材质和光照，标签只作归纳。

| 成图媒介 | 身份与造型重点 | 可写入提示词的表现要求 | 避免的误转译 |
| --- | --- | --- | --- |
| 2D 平涂／赛璐璐 | 脸部外轮廓、五官位置、眼形、发型剪影与色块关系 | 依据参考选择线条粗细、阴影层数、色块边界与局部渐变，五官和纹样随头部角度变化 | 因追求高清而加毛孔、湿润皮肤或摄影散景 |
| 绘画式 2.5D | 按参考保留动漫化、半写实或写实的五官比例；用面部块面和转折解释体积 | 软硬边结合，依据光向组织额头、眼眶、鼻颊和下颌明暗；发束与衣褶保留相应绘画概括 | 默认大眼动漫脸，或把所有边缘磨圆、表面抹成塑料 |
| 风格化 3D | 保留角色的造型夸张程度、头身比、眼形与标志结构；把平面符号转为连贯立体形状 | 轮廓、面部体块、眼球与眼睑接合清楚，材质响应分区；阴影可硬可软，按选定风格执行 | 把三维化直接等同真人化，统一缩眼、增鼻梁或添加照片皮肤 |
| 写实 CG | 用可观察的面部结构建立可信体积，服装结构和表面材质具备空间厚度 | 描述实际需要的皮肤反光、眼睑及眼球反射、发丝方向性高光、布料与金属响应，让受光和形体对应 | 只堆 PBR、光追、引擎名或假造参数，把写实等同油亮和满屏微纹理 |
| 真人摄影 | 优先保持目标人物可观察的肖像关系，并适配底图头部角度、表情和透视 | 统一脸部、耳部、颈部和身体的肤色受光、细节尺度、清晰度及景深，保留有依据的皮肤与镜头表现 | 用“漂亮／标准脸”覆盖身份，继承底图人的下颌和鼻部，只把目标五官贴上去 |

### 跨媒介的身份重建

- **2D → 绘画体积或风格化 3D**：从目标角色的眼形、眼距、面部长宽、鼻口位置、下颌和发际线关系出发，在新视角重建额头、眼眶、鼻颊、下颌等体积。参考中省略的结构做与选定造型一致的最少补全，不沿用底图人物的脸部体块，也不把一套固定动漫脸套给所有角色。
- **动漫 → 真人摄影或写实 CG**：仅在用户明确要求真人化／写实转译时进行。保留可迁移的特征，以写实结构重新解释夸张或省略处；单张动漫图无法确定唯一的真人骨相、族裔或全部隐藏结构。对确实影响相似度的歧义简短说明，不把自行选择的解释声称为角色真实长相。
- **真人 → 真人**：比较目标人物在参考中可见的脸部长宽、眼形与间距、鼻部轮廓、口唇关系、颧颊与下颌，不照搬底图人的骨相。把身份结构与转头、表情、光照分离，再按目标镜头重新投影；没有证据的侧脸和被挡部位不作精确断言。
- **立体／真人 → 2D**：按所选画法概括明暗与纹理，同时保留辨识关系，不只描底图人物轮廓后替换颜色。

头部角度和表情变化明显时，不要求目标参考的正面五官像素位置不变；要求的是同一人物在该角度和表情下仍连贯。只给一个视角的参考时保守处理未见部分，不因身份图分辨率不同就默认要求补图。

## 3. 提取绘制完成度与质感迁移规律

“赛璐璐／2.5D／3D”不足以限定成图。确定媒介后，再观察参考图怎样组织明暗、边缘、材质和细节，形成一套本次采用的绘制规律。这里的“绘制完成度”指概括与细化的方式，不是分辨率高低或作品优劣，也不是默认增加细节。

| 观察项 | 提取并迁移的内容 |
| --- | --- |
| 人物内部明暗范围与局部反差 | 分别看脸、头发和服装各自的亮暗跨度、暗部层次及相邻面的反差；区别固有深色与照明阴影，不只比较全图最亮和最暗像素 |
| 阴影块面 | 主阴影是少量连贯大块还是密集细碎转折，形体通过哪些明暗面成立；按该概括程度重新绘制新角色 |
| 软硬边与线宽 | 哪些轮廓清楚、哪些边缘融入暗部，描线粗细和对比如何变化；不把柔和体积统一磨平，也不把所有边缘锐化 |
| 材质高光 | 按皮肤、头发、布料、金属等观察高光形状、宽度、强度和覆盖范围；存在金属扣不代表整套服装都要亮面 |
| 细节密度与焦点 | 哪些部位细化、哪些合并成大色块，发丝、衣褶和纹理的密度如何随焦点变化；保留必要结构，概括表面碎细节 |
| 人物占比与取景 | 主体占比、裁切、景别和透视怎样影响观感；遵守已锁构图，不能因想展示所有配饰而擅自改为远景或全身 |

将**风格规律**与**原人物及背景内容**分开：不因保留阴影画法而复制原角色的发色、服饰或背景装置。角色辨识与服装结构按 [character-identity.md](character-identity.md)，场景职责按 [adaptation-and-variants.md](adaptation-and-variants.md) 执行。

- **参考呈现柔灰、简化绘制时**：迁移柔和的内部明暗跨度、低局部反差、连贯阴影和适度细节概括。目标角色原有的黑、白、红等固有色仍清楚可辨；不一律提亮黑色、降低饱和度或覆盖灰色滤镜。保留扣带、拉链、护具、层叠衣片等功能性结构，只按参考简化其阴影、高光和表面纹理。
- **参考呈现硬朗、高反差时**：迁移其明确块面、硬边及有选择的强反差，不能套用固定柔灰处理；材质高光的强度与位置仍由该参考和场景决定。
- **场景变化时**：受光方向按新空间重建，同时维持已确认的明暗概括、边缘和细节规律。原图局部光效不自动升级成大型漩涡、舞台光束或强轮廓光；新增光效须有本次需求或已选场景的依据。

画风修正通过重绘明暗块面、边缘和细节概括完成，不靠全局模糊、降低分辨率或添加颗粒模拟。“反 AI／高清／干净”不强制提高锐度、反差或微细节；绘制可以简洁，同时让焦点与必要结构保持清楚。

## 4. 让人物接受本次场景的光照

先确认空间、主光方向、光源大小所对应的阴影软硬及环境色，再让脸、头发、颈部、身体与服装一起受光。不能只改脸上的亮度或沿人物外缘加一圈轮廓光来伪装融合。

- **存在锁定项**：逐项遵守本次锁定的场景布局、镜头或光照；仅锁场景不自动禁止用户另行要求改光，仅锁光照也不自动锁住全部陈设。保留光照时维持光源方向与明暗关系，依据新角色的脸部体积、发型、衣领和姿势重新计算受光、投影与遮挡，不沿用原人物的鼻影、下颌影和皮肤反光。不为增强质感无故新增光源或移动窗户。
- **已授权适配新场景**：先选定新空间与光照，再重建人物和环境的共同受光、反射与接触阴影。继承底图画法不代表继续保留底图不适用的光向；用户锁定光照时选择能支持它的空间。
- **自然光**：按可观察或已设计的窗、天空与遮挡描述入光方向、明暗范围、阴影软硬和环境反射色，不无依据追加太阳光束、逆光光晕或第二个主光。
- **人造光**：明确灯或发光表面的所在方向、影响范围及颜色，脸部与衣服接受同一光源。局部彩色边光不覆盖角色全部固有颜色，镜面高光不等于物体自发光。
- **反射**：高光随光源、视角和材质变化；玻璃或镜面反射遵守同一反射平面，按视野包含应出现的头部、颈肩、衣物和背景，并由边框与遮挡裁切。不要生成独立漂浮的脸部反射，或把背景无依据复制为第二套场景。

材质只选当前画面相关的几项分区描述：皮肤高光与粗糙程度、眼部反射、头发方向性光泽、织物漫反射、金属反射、透明材料透射等。按成图媒介表达，不把真人毛孔、三维表面微纹理或手绘笔触无差别加给所有分支。

## 5. 写成一套明确的渲染指令

最终人物替换或 C 完整画面提示词至少落实身份转译、选定媒介、相关材质和共同受光；按需补充焦点、边缘及后期。发际线、眼睑、耳根、下颌和衣领之间的明暗连接应连续，脸、脖子和身体不呈现不同清晰度、磨皮程度或纹理尺度。摄影的焦平面与景深、绘画的边缘概括各按自身规律处理，不要求全画面等量清晰。

以下是组织骨架，交付时用已选分支的具体内容替换括号，不保留候选列表或不适用句子。A 的身份插槽可保留；B 纯身份段和纯风格提取不使用此完整骨架。

```text
渲染统一：成图采用[已选媒介及具体造型、边缘与明暗方式]。依据【新角色参考／设定】的[本次可观察或待提供的身份结构]重建当前角度和表情下的面部与身体，保留辨识关系及固有颜色，移除身份参考自带的原光照和固定高光。皮肤、头发及[当前关键衣物／配饰]分别采用[与本次媒介相符的表现]。整个角色接受[已选场景的具体入光方向、阴影软硬与环境色]，头颈、衣领及实际接触处的遮挡阴影连贯；[当前适用的边缘、清晰度与景深关系]一致。
绘制完成度与质感迁移：沿用参考的[人物内部明暗范围与局部反差]，阴影组织为[块面大小、连贯性与概括程度]；轮廓采用[软硬边和线宽规律]，各材质采用[高光形状、强度及覆盖范围]。细节集中在[焦点部位]，其余区域按[概括程度]处理，保持[人物占比、景别与裁切]。保留新角色的固有颜色及功能服饰结构，不用全局灰化、模糊或额外光效代替重绘。
```

自然化／反 AI 约束按 [naturalism.md](naturalism.md) 选择具体项目，写入同一最终代码块。优先修正重复纹理、无受力衣褶、材质同质化、光影断裂和焦点失衡，不用额外颗粒、粗糙笔触或满屏细节掩盖身份与结构问题。不凭空添加相机、焦段、引擎、采样数等参数，也不承诺提示词必然保留相似度。

## 6. 清晰度与实际验收

分别判断三件事：

1. **身份信息是否可辨**：看脸部关系、发型分区和关键配饰能否辨认，不只看总像素。关键特征确实模糊且影响任务时说明不确定项；A 模式仍交付身份插槽。
2. **渲染是否一致**：低清身份参考不必先放大到与壁纸等大；违和可能来自面部结构、材质、光向、边缘或细节尺度，不能只凭尺寸归因。
3. **输出像素是否属实**：“高清／16K／壁纸”不保证尺寸或原生细节。实际出图或修复时才按工具能力设置并核对文件尺寸；插值放大不恢复已丢失信息，生成式补细节可能改动身份。

仅交付文字时核对参考职责、单一分支和要求覆盖，不声称已验证成图。实际获得生成图后，按顺序检查：身份与面部关系 → 角度、表情及身体连接 → 人物与场景受光／反射 → 材质和焦点层次 → 实际尺寸。姿势、文字和手足结构仍按主文件独立验收；纯风格任务只检查本次风格要求。

实际有成图时，将成图与本次风格参考按相近显示尺寸并排检查整体，再查看人物焦点局部；不能只看到提示词写了“柔灰／赛璐璐”就判定画风已还原。逐项对照内部明暗、阴影碎度、软硬边／线宽、材质高光、细节分配及主体占比，明确哪项接近、哪项偏离；允许身份固有色、已授权场景与光向不同。若人物被画得过亮、过硬、过碎或过度精细，限定相应面部／服装／发束区域重绘，保留身份、功能结构和已正确构图，不用全图降饱和、模糊或缩小来假装修复。只有文字方案时不虚构这一步的成图检验结论。

发现问题时明确区域、可见错误与修正目标，例如“保留头部角度与表情，修正眼形和下颌以符合身份参考”或“保留窗外布局，重绘人物头颈和外套在玻璃上的连贯反射”。锁定已正确区域，避免因修脸全图换人，或只用磨皮、锐化、换背景掩盖问题；实际修改和再次生成仍须在用户授权范围内进行。
