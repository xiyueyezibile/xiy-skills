# 去 AI 味：按画面选择自然化约束

把“去 AI 味”落实为具体视觉约束，不把它当作保证真实感的万能标签。交付完整画面、风格提取、人物替换或场景创作提示词时默认执行，不等用户再次提醒。最终代码块内明确标注“自然化／反 AI 约束”，或合并进有该标识的画法、材质段；选二至四项即可，不机械追加全文。B 仅提取身份时不增加未经指定的渲染方案，用户明确关闭时遵从。

先按媒介选用：摄影参考下方十项；动漫、绘画式2.5D和3D优先参考下一节；平面与像素等设计保留自身的规则性与简化造型。本页不能用于判断一张图是否由 AI 生成，也不保证生成结果。

## 动漫、2.5D 与 3D 的默认自然化

按当前画面选择最相关的二至四项，并用具体对象落地：

- **发束、纹理与装饰**：发束的大小、走向和疏密依发型结构组织，高光沿曲面与光源展开；纹理随表面透视、遮挡和形变变化。避免无结构依据的重复弧线、均匀细丝和漂浮碎纹，但保留角色设定中的对称发型、重复纹样或规则装饰。
- **线条、边缘与细节层次**：绘画可按焦点、光照及遮挡分配软硬边和细节；赛璐璐、矢量或像素造型可保留清楚一致的轮廓与硬边。自然化不强制变成粗糙手绘、浅景深或次要部位模糊，避免处处过锐、无意义的密集细节和描边光晕。
- **材质响应**：皮肤、头发、织物、金属与玻璃依据本次材质设定响应光照，高光形状、宽度和强度有依据。保留本来就光滑或高反射的材质，不一概降低光泽，也不为动漫人物加入摄影毛孔；避免所有表面共用同一种油亮反光或磨皮质感。
- **衣褶与接触**：衣褶由剪裁、拉伸、关节动作和支撑决定，纹样跟随布面变化；接触阴影和形变适合实际受力。避免用无受力依据的碎褶或细节掩盖形体，不为自然化改变指定衣服或动作。
- **光影统一**：投影、反射、环境染色和接触暗部对应同一套场景光源。多光源、霓虹、暖光和辉光若属原风格则保留，限制无依据的额外补光、全身轮廓光和漂浮光点。

“结构正确、材质有区别、边缘干净”只有落实到当前对象的具体表现，才能构成有效约束。例如赛璐璐角色可写“发束按粗细疏密组织，布纹随褶皱转折，高光依衣物材质分区，重点部位清楚而次要区域概括”，不照搬其他图的发色、场景或半厚涂笔触。

多图共用段保留自然化规则，独立提示词各自包含适用规则。小差分只变化已授权的动作或表情，不能借自然化改变脸型、发型、衣服或故意增加瑕疵。

## 十项约束及其边界

以下十项以日常摄影为主要适用范围。

| 项目 | 可写入提示词的描述 | 适用条件与保留项 |
| --- | --- | --- |
| 1. 减少多余黄偏 | 中性白平衡，白色物体不整体泛黄，肤色自然 | 修正无意的整图黄滤镜；日落、烛光、暖灯和有意暖调保留，不把所有黄色区域去掉 |
| 2. 减少模板化居中 | 主体略偏左或偏右，采用三分法取景，留白与视线方向协调 | 自然抓拍且构图允许调整时选用；证件照、建筑对称、产品正面和原图关键居中布局保留 |
| 3. 减少塑料肌肤 | 保留与拍摄距离匹配的肤色起伏和皮肤纹理，避免过度磨皮 | 近景可加入毛孔、细绒毛、细纹；远景不硬加毛孔，不额外制造年龄特征；动漫人物不套真实皮肤 |
| 4. 让光照关系一致 | 以一侧窗光为主要光源，阴影、反射和接触暗部与光向一致，允许环境反射补光 | 适合窗边场景；室外、阴天、多灯场景按实景写。单一主光不等于只有一个光源，阴影可柔和 |
| 5. 让焦点有层次 | 焦点落在主体，背景按距离适度柔化，虚化边缘自然 | 参考图或任务需要浅景深时采用；风景、建筑、群像、平面海报和清楚可见的环境细节可保持清晰。只有用户指定或需要目标拍摄设定时写 f/1.8，不能反推出实际光圈 |
| 6. 减少广告修图感 | 日常快照，克制的曝光、对比和锐化，不做明显美颜或滤镜效果 | 用户需要手机随拍时可写手机拍摄观感；不擅自改变专业摄影用途。用可观察的成片效果替代不可验证的“完全无加工” |
| 7. 加入适量生活痕迹 | 材质有细微磨损、褶皱和正常使用痕迹，物品摆放符合场景用途 | 参考图已有或用户允许补充时使用；不强制加脏乱，不在干净设计或新品展示中制造污渍。装饰纹理也不应各处完全相同 |
| 8. 减少刻意表情 | 表情和身体动作放松，视线落在正在关注的事物上 | 适合有人物的生活抓拍；原图的直视、微笑、表演姿势或广告表情可能是核心内容，按任务保留 |
| 9. 控制文字与标志 | 不额外添加无意义文字、标志或水印 | 没有文字需求时可用；包装、招牌、海报和品牌设计的必要文本保留并单独检查，不能为避免文字问题抹掉内容 |
| 10. 减少过度特效 | 控制非必要光晕、漂浮光点、HDR和过锐边缘，保持符合场景的饱和度与反差 | 无根据的特效可以删除；逆光、舞台灯、镜头光斑、霓虹、鲜艳插画和有意特效按参考保留 |

## 如何合并进反推提示词

从实际画面或用户要求中挑选最相关的二至四项。不要无差别追加十项，也不要把修改目标当作原图事实。例如，原图暖调但用户要求中性肤色，应说明这是自然化调整，而不是宣称原图使用中性白平衡。

优先把修正放回对应句子：配色段处理黄偏，人物段处理皮肤与表情，光照段处理阴影，构图段处理主体位置，并在该段标题标注“自然化／反 AI”；也可在同一代码块内单列简短约束段。不要在正文要求居中，又在末尾追加“禁止居中”。

原图结构明显有问题且用户要求改善时，可以补充局部连贯性要求，如手与物体接触合理、眼睛视线一致、物体轮廓和遮挡关系连续。不要用额外噪点掩盖结构问题，也不要默认添加污渍、歪斜或瑕疵。

## 日常摄影：可复制的补充句

仅用于用户希望日常摄影自然化、且以下要求不冲突的场景。没有人物时删除皮肤部分；参考图依赖暖调时改写白平衡部分；必要文字继续保留。

```text
自然化／反 AI 约束：保持日常快照的自然观感，白平衡中性、肤色自然，保留与拍摄距离相符的皮肤和材质纹理；主光方向明确，阴影与环境反射一致，焦点和景深符合场景；避免过度磨皮、锐化及无根据的光晕，不额外添加文字、标志或水印。
```

此后缀不固定改变构图、背景清晰度或相机设定。若用户希望偏左构图、手机观感或浅景深，将它们写入主提示词。

## 动漫与平面设计：保留风格的自然化

以蓝橘 Y2K 海报为例，保留高饱和撞色、居中动漫人物、清晰街景和必要的像素标签。去 AI 味可从线条、阴影连贯性、纹理分布和图形层级入手：

```text
自然化／反 AI 约束：保留蓝橘高反差配色与原有海报布局，线条连贯，局部粗细有自然变化；人物五官、手势、衣褶和遮挡关系清楚一致。网点与磨损按区域分布，疏密和破损形状有所变化，避免整图铺满重复噪点；必要文字保持清晰的排版层级，不额外添加无意义标签、塑料高光或无根据的光点。
```

不添加摄影毛孔、f/1.8 虚化或中性低饱和要求；不因为“去 AI 味”删去构成 Y2K 风格的符号与文字。

## 校准场景

- **窗边生活人像，用户要求更自然**：可选中性白平衡、真实皮肤、窗侧主光和放松表情；背景是否虚化由画面距离和任务决定。
- **日落广角风景，用户要求忠实反推**：保留暖光和清晰远景；只处理无根据的光晕、过度锐化或不连贯的物体形状。
- **蓝橘动漫海报，用户要求减少 AI 感**：保留居中、高饱和、文字和清晰线稿；选用轮廓连贯、自然变化的纹理和明确图形层级。
- **带品牌文字的产品图，用户要求干净准确**：保留必要标志与文字、干净背景和指定对称布局；不擅自加生活杂乱或移开主体。
