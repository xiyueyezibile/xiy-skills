# 视觉术语校准与反推示例

用于处理混合媒介、纠正过度概括，以及展示观察如何进入提示词。本例来自一张蓝橘配色的动漫人物海报；这里只记录视觉分析，不保存用户图片，也不依赖临时附件路径。

## 易混概念

| 词语 | 应有的视觉证据 | 谨慎写法 |
| --- | --- | --- |
| 纯像素艺术 | 主体造型、边缘与细节普遍以离散像素阶梯构成 | 主体是流畅线稿时，改为“加入像素字体和像素图标” |
| 像素抖动 dithering | 用有规律或噪声状的离散像素混合表现明暗、色阶 | 分不清时描述“颗粒或像素状噪点”，不指定算法 |
| 半色调 halftone | 成组的印刷网点，常以疏密或大小表现明暗 | 写清出现在阴影、衣物或背景的哪个区域 |
| 做旧、磨损 | 不规则掉色、刮痕、斑驳与破损边缘 | 不把所有磨损称为像素抖动 |
| 扁平构图 | 画面强调色块、剪影和排版层级 | 不意味着没有透视、体积或任何阴影 |
| 平涂 / 赛璐璐 | 以少量色块和硬边阴影塑形 | 保留看得见的局部高光与阴影，不写“彻底消除光影” |
| 荧光、发光 | “荧光色”可表达鲜亮色感；自发光需有光晕或照亮周围的证据 | 只看见高饱和橘色时写“亮橘色”，不自动加入霓虹光晕 |
| Y2K、波普 | 多个相互支持的时代图形、数字界面、字体与高反差色块线索 | 风格标签后仍要写具体画面特征，不能让标签替代描述 |

“黑体”通常指字体；绘画边缘用“粗黑轮廓线”。“照片噪声”“纸张颗粒”“仿印刷网点”和“JPEG压缩块”也不是同一种纹理。

## 蓝橘动漫海报：观察到指令

| 看见的特征 | 可复用的生成描述 |
| --- | --- |
| 中央动漫人物占据大部分画面，周围图形贴边分布 | 大幅主体剪影配合边缘环绕的海报图形布局 |
| 电光蓝背景、橘色裤装与图形，黑色及米白色穿插 | 电光蓝主色与亮橘色强调色对撞，以黑色、米白色组织轮廓与信息 |
| 人物轮廓流畅；文字、爱心、光标等具有像素阶梯 | 动漫线稿主体与像素字体、像素图标相结合 |
| 发丝和皮肤仍有明暗，阴影部分出现网点 | 以平涂和少量赛璐璐阴影塑形，局部保留高光及半色调纹理 |
| 蓝底叠加黑色街景、电线与招牌线稿 | 用简化的黑色街景线稿形成密集背景层，保留轻度透视 |
| 黑色星芒、橘色圆弧、螺旋与旧式窗口、进度条 | 边缘环绕高反差几何符号与复古数字界面元素 |
| 衣服、背景和标签有不规则破损颗粒 | 在不同图层叠加仿印刷斑驳与磨损，而不是统一套一种噪点 |

## 只提取风格的提示词

```text
将[主体]呈现为一幅动漫插画与Y2K复古数字图形相结合的平面海报。主体以大幅剪影占据画面中心，边缘环绕像素字体标签、旧式窗口、进度条和贴纸图形。采用高饱和电光蓝作为大面积底色，以亮橘色形成强烈对比，辅以黑色和米白色组织轮廓与文字层级。主体使用流畅线稿和清晰的黑色轮廓，以平涂及少量硬边阴影塑形，保留局部高光。背景叠加简化的黑色线稿，边缘布置锐利黑色星芒、橘色同心圆弧与螺旋图案。局部加入半色调网点、像素化小图标与斑驳磨损，形成鲜明、躁动的千禧年街头海报气质。
```

这版保留了构图、颜色与画法，移除了原图人物、服装和具体文字。街景是内容元素：需要保留街头场景时加入“复古街景、电线和招牌线稿”；迁移到其他题材时，用适合新主体的背景元素替换。

## 完整画面反推的提示词

```text
方形动漫人物海报。一个浅棕色短发、戴字母发夹的动漫少女占据画面中央，身体略微倾斜，一只眼睛眨起，另一只眼睛为明亮蓝色；抬起一只手，在脸旁比出V形手势。她穿米白色短款宽松T恤，胸前印有蓝橘撞色的大字样和像素爱心，搭配亮橘色长裤、黑色腰带、金属链条与星形腕带。人物从头部延伸至画面底部，裤腿在边缘裁切，外轮廓带有浅色描边。采用流畅动漫线稿、清晰黑色轮廓与平涂色块，保留头发和皮肤的少量高光、阴影，局部加入半色调网点。背景为高饱和电光蓝，叠加密集的黑色街景、电线和招牌线稿。四周环绕黑色星芒、橘色同心圆弧、黑橘螺旋、像素字体标签、爱心和光标图标，左下分布旧式电脑窗口与加载进度条，右侧设置竖向色条，右下设置橘色姓名牌。整体融合Y2K复古数字图形与波普海报排版，在背景、服装和图形标签上叠加斑驳磨损与仿印刷颗粒，保持强烈的蓝橘对比。
```

此例只描述相关文字的用途与视觉形态。若用户要求精确复刻文字，应另行保留清楚可读的文本，不能把不清晰文字猜成确定内容。

## 改稿时的取舍

- 把“整体纯像素艺术”改为“动漫插画与像素UI装饰结合”，避免改变人物造型。
- 把“光影彻底扁平化”改为“平涂为主，少量明暗塑形”，避免丢失实际可见的层次。
- 把“布满像素抖动”改为“局部网点、像素图标和斑驳磨损”，避免让噪点淹没主体。
- 保留蓝橘色块关系、主体占比与装饰分布，这些比“视觉奇观”等修辞更能约束结果。
- 未经试生成，只能确认描述与参考图是否一致，不能宣称该提示词一定复现原图。
