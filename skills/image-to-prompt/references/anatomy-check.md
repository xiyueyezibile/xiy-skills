# 肢体完整性：先分清遮挡，再检查连接

用于包含人物的完整反推、替换模板、场景创作及实际生成图验收。B 纯身份提取和只提取画风不增加原姿态约束。遵从目标角色已有的肢体设定；正常人类的两臂、两手、两腿、两足是实际结构数量，不等于当前画面全部可见。

## 1. 写提示词前建立肢体归属

逐个人物在内部核对各条手臂、各条腿；不必把完整分析表交给用户。

- 为每条肢体记录所属人物、起点与可见走向、关键关节、接触任务、遮挡物及末端位置。角色自身左右不能确定时，用画面侧别、前景／后景或对应动作区分，不猜左右标签。
- 区分完整可见、局部可见、有具体遮挡依据、裁切在画外、无法确认五种情况。只看到一只手或一只脚，不直接判定缺失；遮挡必须有符合空间的物体或身体部位，不能凭“可能在后面”给明显断肢开脱。
- 对可见手臂追踪肩—上臂—肘—前臂—腕—手，对可见腿追踪髋—大腿—膝—小腿—踝—足；隐蔽段只核对进入和离开遮挡的合理路径，不声称已看见被挡关节。
- 蜷坐、盘腿、交叠手、抱膝或多人接触时，将每只手、每个膝、每条小腿和每只鞋分别归属，不能让两条腿共用一只脚、两只手接在同一腕上，或把同一肢体的两个片段计成两条。
- 袖口、裙摆、发束、阴影和道具不是肢体。分不清腿的交叉方式或一段轮廓归属时，保留有依据的遮挡与屈曲，不补写翘腿、额外手脚或新姿势解释。

## 2. 将当前画面需要的关系写进提示词

在“人体与物理约束”中简短落实实际相关的肢体起点、弯曲、遮挡和终点，不能只有“无多手少腿、结构正确”。手指与脚趾仍按主文件独立要求处理。

例如双手叠在膝上、双腿蜷起的姿势：分别说明两个手腕从各自前臂接入叠手区域；两条腿各自屈膝，前景和后景小腿按既定遮挡向各自脚踝延续。脚若在画外或被裙摆挡住，维持这一状态，不为了数齐四肢改变取景或展开双腿。

数量与路径均按目标人物设定执行，不给明确缺肢、义肢、非人类多肢或特殊卡通设定自动增加正常人类肢体；义肢按其连接结构核对。只有上半身的构图不增加腿脚段。

## 3. 实际出图后逐张检查

实际生成了图片或收到结果图时，查看图片本身，按上述归属逐条复核，不能把“提示词写了两臂两腿”当作验收通过。

1. 先确认人数与各自设定数量，再追踪每条可见肢体的起点、关节、遮挡和末端。需要时查看原分辨率或可用的局部放大，识别袖口、鞋口和暗部中真实的结构。
2. 区分应可见却缺失、两肢融合、错接／分叉、重复肢体、正常遮挡／裁切和证据不足。不能只数肤色或衣物凸起，也不能因为见到两只手就忽略断开的前臂或不存在的肘。
3. 按本次已确认的动作方案核对动作任务与支撑；忠实还原或明确锁定动作时，再对照原动作参考。承重手或腿是否仍存在并正确接触，持物是否由实际手握住，膝、踝和手腕是否有不合理反折。多图逐张检查，不能用一张通过代表整组。
4. 明显缺失或错接未解决时，不声称结构通过；不确定处说明可见性限制，不将所有被遮挡部位判为已精确验证。

## 4. 修正与复验

在用户已授权的出图／修图范围内进行局部修正：指出对应人物、肢体、缺失或错接位置，并覆盖必要的关节连接、袖口／鞋口或接触边界；固定正确的脸、姿势、服装、画法和背景。补手应连回正确手腕与前臂，补脚应连回正确脚踝与小腿，不能在空处加一个孤立末端。

不通过裁掉、用衣物遮住问题、减少肢体或展开身体改姿势来伪装修复。只有用户要求改变取景或姿势时再改变。修完重新查看整张图并复核各条肢体，防止局部补全同时新增手脚、破坏另一侧或改变接触。无法完成时如实说明未解决部位，不能无限重试或假称已修复。

只写提示词时，交付的是结构与遮挡要求，不声称已验证未来成图。
